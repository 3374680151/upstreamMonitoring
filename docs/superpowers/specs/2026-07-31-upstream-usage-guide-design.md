# Upstream 使用与配置教程设计规格

**日期：** 2026-07-31
**交付物：** `docs/upstream-usage-guide.html`
**状态：** 用户已明确要求直接制作

## 目标

制作一个无需构建、可离线打开的单文件中文 HTML，用于审查 Upstream 当前配置逻辑并指导实际部署、站点配置、主站连接、登录态同步、推送、备份和排障。

## 事实来源与边界

内容按以下优先级核对：当前 `app.py` 与 `apps/web` 源码 > 当前部署/迁移脚本 > README 与产品文档 > 23 条历史 Upstream 任务记录。历史会话只用于解释设计演进和高频误区；与当前代码冲突时，以当前代码为准。

教程不得包含 `.env`、数据库、站点 Token、渠道 Key、密码、Cookie、Webhook 等真实敏感值。示例统一使用 `example.com`、`change-me` 或 `<占位符>`。

## 信息架构

1. 首屏：版本日期、适用范围、快速入口和本次会话审计摘要。
2. 配置逻辑：严格区分本地监控节点 `sites`、主站连接 `admin_sites` 和远端真实渠道。
3. 快速开始：本地开发、本地生产、Docker 三套流程。
4. 环境变量：数据库、网络、超时、控制台密码和时区的配置表。
5. 渠道监控：NewAPI 与 sub2api 的认证方式、字段和推荐选择。
6. 主站监控：平台能力边界、Base URL 匹配和渠道 Key → 用户分组 → 倍率链路。
7. 浏览器扩展：安装、同步条件、权限范围及不能绕过人机验证的边界。
8. 检测与变化：10 秒扫描、按站点间隔采集、快照、diff、通知链路。
9. 余额与模型：实时查询接口、缓存与历史快照的区别。
10. 推送：企业微信与 SMTP 的保存、测试和启用顺序。
11. 备份迁移：MySQL 备份、恢复、SQLite 幂等迁移及 `--truncate` 风险。
12. 安全审查：公网访问、数据库明文敏感字段、后端隐藏写接口、快照增长和代理缓存风险。
13. 验收清单与故障排查。

## 视觉与交互

- 遵循 PriceAI：`#f9f9f9` 页面底、白色面板、`#45bf78` 品牌绿、细边框、高密度信息、浅色默认和暗色主题。
- 桌面端使用固定侧栏目录与窄正文；移动端使用顶部工具栏和目录抽屉。
- 提供全文搜索、章节定位、代码复制、主题切换、打印样式和返回顶部。
- 使用内联 SVG 图标，不依赖网络、字体 CDN 或第三方脚本。
- 所有功能可键盘访问，有跳转主内容链接、可见焦点、ARIA 标签和 `prefers-reduced-motion` 支持。

## 验收标准

- 双击 HTML 即可完整使用，断网时无资源缺失。
- 375、768、1024、1440 像素宽度无页面级横向溢出。
- 搜索、目录、复制、主题切换和打印按钮工作正常。
- 代码示例与当前仓库一致，且不出现真实密钥。
- 明确指出主站实时数据不进入 `sites` 的定时快照与变化通知。
- 明确指出当前 UI 与后端主站写接口的能力边界差异。
